🎮 Spielerklärung

Ziel: Baue ein riesiges Rechenzentrum auf und produziere so viele Daten wie möglich – von einzelnen Bits bis hin zu Exabytes.

🖱️ Manuell klicken
Am Anfang sammelst du Daten per Klick auf Daten sammeln. Jeder Klick bringt 1 Bit.
🏢 Gebäude kaufen
Kaufe Gebäude die automatisch Daten produzieren. Jedes Gebäude produziert pro Sekunde Daten. Höhere Gebäude schalten sich erst ab einer bestimmten Datenmenge frei.
Die Reihenfolge: IT Mitarbeiter → Mini Server → Server Rack → Blade Cluster → Datacenter Halle → Cloud Region → Hyperscale Campus → Quantenrechner
⛓️ Gebäudekette
Höhere Gebäude unterstützen niedrigere – sie übertragen einen Teil ihrer Leistung nach unten und verstärken diese zusätzlich. Je mehr höhere Gebäude du hast, desto mehr profitieren die IT Mitarbeiter.
📦 Kaufmenge
Wähle x1, x10, x100 oder Max um mehrere Gebäude auf einmal zu kaufen. Max kauft so viele wie du dir leisten kannst.
🔬 Gebäude-Upgrades
Ab 15 MB schalten sich Upgrades frei die einzelne Gebäude dauerhaft stärker machen. Jedes Upgrade verdoppelt die Produktion des jeweiligen Gebäudes.
🧪 Forschung
Offline-Speichererweiterung: Verlängert die Zeit für Offline-Produktion um je 25 Minuten pro Kauf.
KI Optimierung: Einmaliger Kauf der die gesamte Produktion dauerhaft verdoppelt.
🏆 Prestige
Wenn du genug Daten gesammelt hast kannst du ein Prestige machen. Dabei wird der Fortschritt zurückgesetzt, aber du erhältst einen dauerhaften Produktionsbonus von +25% pro Stufe. Jede weitere Prestige-Stufe kostet mehr.
😴 Offline-Produktion
Wenn du das Spiel schließt läuft die Produktion im Hintergrund weiter – bis zum Offline-Limit. Standard sind 25 Minuten, erweiterbar per Forschung.

ℹ️ Formelhilfe

Transfer: Höhere Stufe überträgt 0% ihrer Leistung an die darunterliegende Stufe.
Support: Zusätzlich wird das Ziel mit einem Faktor verstärkt (abhängig von der Geber-Leistung).
Rang: Jede Stufe gibt +0% auf die Gesamtproduktion.
Softcap: Ab 0/s und stärker ab 0/s wird Wachstum gedämpft.
